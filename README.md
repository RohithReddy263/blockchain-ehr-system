
## 🏥 Blockchain-Based EHR System

A full-stack decentralized Electronic Health Record management system built on Ethereum blockchain. 
Patients have full control over their medical data — doctors can only access records after receiving 
explicit permission from the patient, enforced at the smart contract level.

### 🔑 Key Features
- 🔒 Immutable medical records stored on Ethereum blockchain
- 👤 Patient-controlled access permissions (grant/revoke anytime)
- 🩺 Role-based access control (Admin, Doctor, Patient)
- 📋 Smart contract enforced authorization (Solidity)
- ⚡ Real-time REST API (Node.js + Web3.js)
- 🖥️ Interactive React dashboard

### 🛠️ Tech Stack
- Blockchain: Ethereum (Hardhat local network)
- Smart Contract: Solidity 0.8.19
- Backend: Node.js, Express.js, Web3.js v4
- Frontend: React 18
- Tools: Hardhat, npm
